## Implementation of DESIRE 
Paper: https://openaccess.thecvf.com/content_cvpr_2017/papers/Lee_DESIRE_Distant_Future_CVPR_2017_paper.pdf
Third party repo: https://github.com/AkashGanesan/desire-pytorch

The repo was adapted, changing the following aspects:

- Explicit iterative refinement loop
- Simplified ranking rollout
- Velocity encoding
- Static vessel attributes
- Target-centric prediction

(For more details see master thesis section 3.3.4)
